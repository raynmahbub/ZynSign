# Release-surface deferrals — staged features the app cannot show yet.
#
# `ReleaseFeature` promises a stop. A promise is only honest if the app holds a
# surface the gate can reveal, so `Scripts/audit_release_gating.py` requires
# every feature to be either referenced by the app's own source or listed here
# with the reason it is not.
#
# An entry is a recorded decision, not a suppression: it says the feature is
# scheduled on the train and the surface has not been built, so the stop it
# names would reach users with nothing to show. Delete the entry the moment the
# surface exists — the audit fails on a deferral that has been repaid, so this
# list cannot outlive the gaps it describes.
#
# Format: `<feature> — <reason>`
