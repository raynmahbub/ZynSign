# Brand

The ZynSign identity in five short pages. Everything here is generated from
one master (`Assets/Brand/Source/zpen-mark-1024.png`) by
`python3 Scripts/generate_brand_assets.py`; run it with `--check` before a
tag — a hand-edited asset is reported as stale.

| [Colors.md](Colors.md) | Indigo, ink, paper, surfaces, semantic colours, contrast |
| [Typography.md](Typography.md) | SF Pro in the app, the wordmark, Dynamic Type |
| [Motion.md](Motion.md) | The ribbon gesture, timing, Reduce Motion, the haptic language |
| [Asset-Usage.md](Asset-Usage.md) | Which file to use where — README, GitHub, App Store, print, alternate icons |
