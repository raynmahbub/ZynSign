# Release notes — v0.1.0-alpha.3

## [0.1.0-alpha.3] — alpha3 · Entitlements Studio, Developer Identity Center, and real-device signing resilience

Market `0.1.0` build `9` (`CFBundleShortVersionString 0.1.0`,
`CFBundleVersion 9`), tag `v0.1.0-alpha.3`. Release train `.alpha3`:
this stop switches on **Entitlements Studio** and the **Developer Identity
Center** in Release builds (10 of 18 staged features active; 8 staged for
`.beta1` through `.nova1`).

Alpha 3 opens ZynSign's capability-inspection and identity-governance
surfaces in Release builds while closing critical real-device signing, Apple
ID provisioning, multi-app container, pairing-record, and community-feed
compatibility gaps across the workspace.

### Added

- **Entitlements Studio & Developer Identity Center** *(switched on by
  `.alpha3`)* — read-only comparison of embedded Mach-O XML (slot 5) and DER
  (slot 7) entitlements against provisioning profile allowlists, plus the
  unified Developer Identity Center with team workspaces, certificate and
  profile inspectors, relationship graphs, conflict detection, expiration
  forecasts, and recommended signing identity selection.
- **Unified Free Apple ID & Paid Certificate Provisioning** — pure-Swift
  RFC 5054 2048-bit SRP-6a GrandSlam (`GsService2`) authentication
  (`AppleGSASRP6a` + `URLSessionAppleDeveloperPortalClient`), trusted-device
  two-factor verification, `com.apple.gs.xcode.auth` app-token decryption,
  Xcode `QH65B2` Developer Portal requests, automatic App Group creation and
  assignment (`group.*`), portable `.zcert` bundles, bounded `.p12`
  passphrase recovery, and encrypted DNS revocation-shield profiles.
- **Zero-Slot Multi-App Guest Container & Loopback Device Bridge** —
  `GuestContainerHostService` stages guest IPAs (`MH_EXECUTE` → `MH_DYLIB`,
  `__PAGEZERO` neutralization, `arm64` thinning, signature stripping, and
  ad-hoc signing across guest executables, frameworks, and injected dylibs)
  with isolated multi-account data slots and lossless standalone IPA restore,
  paired alongside `DeviceBridgeController`'s local `lockdownd` / `AFC` /
  `installation_proxy` transport.

### Changed

- **Zeus liquid-glass visual system & native five-tab shell** — crisp
  grouped surfaces without offscreen drop-shadow rasterization, isolated
  `NavigationStack` sheet presentation for Settings sub-workflows, and
  synchronized dual Store / Repository Directory catalog updates when adding
  sources via the UI or `zynsign://source?url=...`.

### Fixed

- **Wildcard entitlements materialize concrete bundle-scoped claims.**
  `ProfileEntitlementDerivation.concreteProfileEntitlements` expands
  `TEAMID.*` `application-identifier` and wildcard `keychain-access-groups`
  entries to `TEAMID.<bundleIdentifier>` across Smart Sign, presets, and the
  signing queue so wildcard profiles pass policy checks and iOS `installd`
  verification.
- **Universal Mach-O thinning, pre-signed binary stripping, loose dylibs,
  and `CodeDirectory` `teamID` propagation.** When `replacesExistingSignatures`
  is enabled, universal (`arm64` + `x86_64`) binaries are thinned to `arm64`,
  existing `LC_CODE_SIGNATURE` load commands are stripped before and after
  load-command patching, loose `.dylib` payloads inside `.app` bundles are
  enumerated and signed, pruned extensions are skipped during preflight, and
  the profile's 10-character Team ID is written into `CodeDirectory`
  (`0x00020200`) across all signed Mach-O binaries.
- **On-device deferred UDID coverage and queue options.** `SigningQueue` and
  `SigningOperationCenter` preserve `sideloadOptions`,
  `replacesExistingSignatures`, `allowDeferredDeviceCoverage`, and paired
  `deviceContext` from interactive runs through queued execution.
- **Community feed normalization, download integrity, and UUID `HostID`
  pairing records.** `EncodedCatalogPayloadDecoder` normalizes AltStore,
  Feather, ESign, and Ksign feed schemas (`apps[].versions[]`, root arrays,
  numeric versions/sizes), `StorePackageTransfer` validates
  `expectedContentLength` and ZIP (`PK\x03\x04`) headers before admitting
  downloads, and `PairingRecordCoding` accepts canonical 36-character RFC
  4122 UUID `HostID`s generated by `usbmuxd` / `lockdownd` / SideStore.

### Known limitations & what this release does not claim

- Unchanged platform boundaries (`UnsupportedFeature`): ZynSign does not
  claim entitlement-free in-app IPA installation, private JIT/usbmux linkage,
  or cloud sync / off-device telemetry.
- Passing CI and Apple `codesign --verify` external validation are source and
  simulator evidence, not physical-device hardware evidence; follow
  [`private-testing.md`](private-testing.md) on hardware.
