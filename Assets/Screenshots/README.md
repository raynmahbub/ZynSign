# Screenshots

`raw/` — simulator captures, 1290×2796 (iPhone 6.7") PNG, named as in `manifest.json`. Not committed until 1.0 is captured.
`store/` — composed output of `python3 Scripts/compose_screenshots.py` (generated; ignored).
`template-preview.png` — the template rendered with a placeholder, so the layout can be reviewed without captures.

Rules: dark status bar, 9:41, 100 % battery, no notifications, Library seeded with synthetic `com.example.*` apps. One headline of at most three words; one subtitle of at most ten. See [`docs/releases/screenshots.md`](../../docs/releases/screenshots.md).
